# 数阵破译 v1.0.0-preview

首个 Android 预览版本，面向初中阶段的数学推理练习与休闲闯关。玩家将数字卡放入数阵，让行、列及交叉区域的数学条件同时成立，通过数感、因数分解、排除和条件组合寻找唯一解。

本版本提供完整的离线单人玩法与 30 个固定关卡，适合下载安装、体验玩法和反馈难度。APK 内的应用版本为 `1.0.0`，包名为 `cn.shuzhen.puzzle.debug`，最低安装要求为 Android 8.0（API 26）；实际设备兼容性仍待真机验证。

## 关卡与功能

| 关卡类型 | 数量 | 内容 |
| --- | ---: | --- |
| 教学 | 3 | 小数阵与直接线索，介绍填数、和、积、差及候选标记 |
| 普通 | 18 | 九宫格，结合行列、对角线和区域条件进行推理 |
| 挑战 | 9 | 更稀疏的交叉线索与差值、倍数关系，需要进一步组合条件 |

- 所有关卡均可自由选择，每个数字恰好使用一次，每关具有唯一解。
- 支持点选填数、触摸拖放、数字交换、擦除、候选标记和撤销。
- 点击线索可高亮关联格子；提示提供推理方向与冲突说明，不自动填入答案。
- 不设倒计时，提供重置确认、通关反馈、本地进度保存与继续游戏。
- 内置全部资源，无需账号，不申请联网或存储权限。
- 适配 Android 返回键和系统安全区，并为较旧 WebView 提供脚本与布局兼容处理。

## 安装

下载 [number-cipher-1.0.0-debug.apk](https://github.com/fading723/number-cipher-android/releases/download/v1.0.0-preview/number-cipher-1.0.0-debug.apk)，将 APK 复制到 Android 8.0 或更高版本的手机，在文件管理器中打开并按照系统提示允许该来源安装。

预览包使用 **debug 调试签名**，用于直接安装试玩，尚非应用商店正式发布包。卸载应用或清除应用数据会删除本地进度。自行从源码构建时生成的调试签名可能与预构建包不同；不同签名的同包名应用不能直接覆盖安装。

从源码构建和使用 USB 调试安装的步骤见 [构建说明](https://github.com/fading723/number-cipher-android/blob/main/BUILDING.md)。
